# Arquivos da análise

- **respostas.xls:** respostas coletadas e informações das entradas.
- **Testes.ipynb:** notebook que realiza as análises.
- **requirements.txt:** bibliotecas necessárias para executar o notebook.
- **README.md:** instruções de uso.

## Como usar

1. Mantenha todos os arquivos na mesma pasta.
2. Com Python 3.12, instale as bibliotecas pelo terminal nessa pasta:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Abra `Testes.ipynb` no Jupyter ou em um editor compatível e execute todas as células em ordem.

No Google Colab, a primeira célula instala as bibliotecas. Envie `respostas.csv` quando solicitado.

Os resultados serão salvos na pasta `resultados_reproduzidos/`, criada pelo notebook.
